## 使用方式

1. 打开全流程文档，复制对应章节的「图片生成提示词」；
2. 用 GPT-image2.5 生成图片；
3. 按上表文件名保存到本目录；
4. 文档中的图片会自动显示，不需要再改路径。

## 说明

- 图片生成前，文档中的图片位置会显示为破图，属于正常现象；
- 中文文字容易出现错字，建议生成后用 Canva / Figma / PPT 覆盖修正；
- 底部标语为整张图的关键信息，建议保持醒目、字号最大。
